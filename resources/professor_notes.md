# Topic: Dictionaries in Python

A dictionary is a data structure that stores key-value pairs.
To iterate over or extract information from a dictionary, Python provides specific methods:

- If you only need the keys (the property names), use the `.keys()` method.
- If you only need the values stored under those keys, use the `.values()` method.
- If you need both at the same time, use `.items()`.

A common mistake is confusing `.keys()` with `.values()` when processing the contents
of a dictionary.
